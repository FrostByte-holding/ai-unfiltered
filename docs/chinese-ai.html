Compute operator METASTONE unveiled TokenFleet, a scheduling framework for LLM inference clusters. Its slides show P95 time-to-first-token down 32.4% and on-target output throughput up about 29.4%.

Oct 21 via Pandaily chinese-ai

Shanghai-based UltraRISC Technology showed UR-CP400, an RVA23-compliant RISC-V processor core IP with 8-wide out-of-order issue. It quotes SPECint2006 above 22/GHz on an FPGA prototype.

Oct 20 via Pandaily chinese-ai

Wuxi-based Stars Micro System launched the C82-4G, which it calls China's first PCIe 6.0 switch, with up to 144 lanes at 64 GT/s, plus an 800G multi-protocol AI NIC and a multi-mode RAID chip.
